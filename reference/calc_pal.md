# Calc color palette (discrete)

Color palettes from LibreOffice Calc. This palette has 12 values.

## Usage

``` r
calc_pal()
```

## See also

Other colour calc:
[`scale_fill_calc()`](https://jrnold.github.io/ggthemes/reference/scale_calc.md)

## Examples

``` r
library("scales")

show_col(calc_pal()(12))
```
