# Calc shape palette (discrete)

Shape palette based on the shapes used in LibreOffice Calc.

## Usage

``` r
calc_shape_pal()
```

## See also

Other shapes calc:
[`scale_shape_calc()`](http://jrnold.github.io/ggthemes/reference/scale_shape_calc.md)

## Examples

``` r
if (FALSE) { # \dontrun{
  library("ggplot2")
  show_shapes(calc_shape_pal()(13))
} # }
```
