# Google Docs color palette (discrete)

Color palettes from Google Docs. This palette includes 20 colors.

## Usage

``` r
gdocs_pal()
```

## See also

Other colour gdocs:
[`scale_fill_gdocs()`](http://jrnold.github.io/ggthemes/reference/scale_gdocs.md)

## Examples

``` r
library("scales")

show_col(gdocs_pal()(24))
```
